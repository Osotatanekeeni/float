# ADR 0002: Design tokens, theming and component base

- Status: accepted
- Date: 2026-11-05
- Milestone: M0 (design tokens)

## Context

DESIGN.md specifies a teal, sage and ivory palette for light and dark, financial status colours,
DM Sans and DM Mono. CLAUDE.md corrects several values that fail WCAG AA and asks for dark-mode
status colours checked at 4.5:1. Components must be customised, never shadcn defaults.

## Decisions

1. **`src/design/tokens.ts` is the source of truth for colour; `globals.css` mirrors it.** A test
   parses `globals.css` and fails if any variable differs, so the contrast tests always check the
   values that ship. Tokens are CSS variables, exposed to Tailwind through `@theme inline`
   (`bg-surface`, `text-ink-2`, `bg-status-caution`).

2. **Contrast is a test, not a review step.** Every text and surface pairing, every status pair in
   both themes, the button label, brand text and focus ring are asserted at 4.5:1 (3:1 for the
   focus ring). The dark status colours are new and were derived to pass; the lowest light status
   pair is 4.77:1.

3. **Theme is `data-theme` on `<html>`, set by an inline script before first paint.** The script
   reads a stored preference (light, dark or system), tolerates blocked storage, and avoids a flash.
   Variables are scoped to `[data-theme]`, not `:root` alone, so the showcase can render a light and
   a dark panel side by side. Without JavaScript the app shows the light theme.

4. **Fonts are self-hosted through Fontsource**, not `next/font/google`, so builds do not depend on
   fetching from Google. DM Sans is the variable font; DM Mono is loaded at weights 400 and 500.
   Money uses DM Sans with tabular numerals (`.money`), never monospace.

5. **Components follow shadcn/ui's structure** (class-variance-authority, Radix Slot, `cn`) but are
   written by hand against the tokens rather than generated by the CLI, which would add default
   styling to undo. Status pills always carry a distinct Lucide icon and a text label so meaning
   never relies on colour.

## Consequences

- jsdom cannot compute colour contrast, so axe in unit tests covers structure and naming only;
  rendered contrast is covered by the token tests and will be checked again in Playwright.
- Adding a token means adding it to `tokens.ts`, `globals.css` and the Tailwind theme, and the sync
  test fails until all agree.
- The open decision on showing kobo is untouched; the showcase uses a static example figure.
